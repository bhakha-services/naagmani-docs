# Project Settings

Manage configuration, metadata, environment variables, and deletion for an active project workspace.

- **Portal Location**: `Projects > [Your Project] > Settings > Project Settings` (`/projects/[slug]/settings`)

---

## Available Settings

1. **Project Name & Description**: Update the human-readable project title and internal description.
2. **Project Slug**: View the immutable project identifier used in API headers and URLs.
3. **Environment Defaults**: Set the default active environment (`test` vs `production`) for new dashboard sessions.
4. **Delete Project (Danger Zone)**: Permanently delete this project workspace, associated API keys, service tokens, and routing policies.

> [!CAUTION]
> Deleting a project is irreversible and immediately invalidates all active API keys and service tokens associated with this project.
