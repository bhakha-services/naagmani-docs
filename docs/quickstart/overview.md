# Quickstart Overview

Get started with Naagmani in 3 simple steps:

1. [**Create an API Key**](api-key.md): Generate a tenant-scoped Naagmani API key.
2. [**Send Your First Request**](first-request.md): Execute an OpenAI-compatible completion request using `curl`, Python, Node.js, or Go.
3. [**Stream Responses**](streaming.md): Stream real-time token chunks using Server-Sent Events (SSE).

---

## Prerequisites

- Access to a running Naagmani OS gateway instance (e.g. `http://localhost:8080` locally or your organization's cloud gateway URL).
- At least one upstream model provider configured (e.g. OpenAI, Anthropic, Gemini, or DeepSeek API key in your project BYOK vault).
