# Organizations

In Naagmani, an **Organization** represents the top-level tenancy boundary for an enterprise or developer team.

---

## Organization Scope & Governance

- **Billing & Subscriptions**: Stripe/Cashfree subscription plans, invoice history, and organization-wide spend limits.
- **Member Management**: Role-Based Access Control (RBAC) with Owner, Admin, Developer, and Auditor roles.
- **Global Compliance Policies**: Security policies (e.g., mandatory PII masking, DLP enforcement, model whitelists) enforced across all underlying projects and environments.
- **Plugin Entitlements**: Enterprise plugin licenses provisioned at the organization level apply to all gateway instances connected to the organization.
