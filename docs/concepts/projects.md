# Projects

A **Project** is a distinct application, service, or team workspace within a Naagmani Organization.

---

## Capabilities of a Project

- **Dedicated Key Vault**: Manage separate BYOK provider credentials for distinct services (e.g. `ecommerce-recommender` vs `finance-fraud-detection`).
- **Granular Spend Caps & Budgets**: Set hard or soft token and USD spend limits per project to prevent accidental budget overruns.
- **Independent Plugin Pipeline**: Configure custom plugin stacks tailored to specific application requirements (e.g., enable heavy RAG for internal search, but lightweight regex filtering for customer chat).
