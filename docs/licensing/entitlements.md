# Capabilities and limits

The effective entitlement controls which paid operations are available and the limits applied to an installation. Check the local portal's license status for your actual grant rather than relying on a static plan table.

Core Free feature identifiers include `router`, `byok` and `plugin_runtime`. Paid capabilities and numerical feature values are supplied by the accepted signed license. A feature identifier in a catalog does not by itself prove an end-to-end product integration is available.

Examples of numerical limits include member/project capacity and audit retention. Values vary by grant and release. User RBAC and project/environment policies are separate checks and can restrict an otherwise entitled operation.

For a self-hosted installation, the local OS verifies the license and expiry. Hosted service plans are administered through Accounts. A local database or UI edit is not a replacement for a valid signed license.
