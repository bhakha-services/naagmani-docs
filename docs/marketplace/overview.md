# Marketplace

Use the Developer Portal's **Marketplace** to discover the artifact types offered by your deployment, inspect publisher/version details and install supported artifacts into the intended project/environment.

Review the manifest, permissions, required capabilities, dependencies, version and installation scope before enabling an extension. A catalog entry, checksum or publisher badge is not a guarantee of a security audit or safe behavior. Only run plugins and tools you trust.

Available artifacts and install actions depend on catalog connectivity, permissions, runtime compatibility and entitlements. Local/offline installations need pre-staged artifacts and dependencies. Installing an artifact does not automatically configure provider credentials or grant a user new permissions.

See [discovery](/marketplace/discover), [installation](/marketplace/installation), [publishing](/marketplace/publishing) and [plugin development](/build/hdks/development).
