# Contributing to Naagmani Documentation

Thank you for contributing to the official Naagmani documentation!

---

## 📝 Guidelines

1. **Clear and Concise**: Write direct, actionable technical documentation without marketing fluff.
2. **Code Samples**: Ensure code examples in `curl`, `TypeScript`, `Python`, and `Go` are syntactically valid and use generic environment variables (`NAAGMANI_API_KEY`, etc.).
3. **Public / Private Boundary**: Never include internal IP addresses, private credentials, staging/production infrastructure details, or private repository URLs.
4. **Markdown Standards**: Use GitHub-flavored Markdown with fenced code blocks and standard table formatting.

---

## 📬 Submitting Changes

1. Fork the `bhakha-services/naagmani-docs` repository.
2. Create a branch (`git checkout -b docs/improve-quickstart`).
3. Make your edits and check for broken markdown links.
4. Open a Pull Request with a clear summary of your changes.
